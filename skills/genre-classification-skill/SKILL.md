# 细粒度题材分类技能

## 前置条件

- 必须已通过 novel-analyzer 完成 genre(男频/女频) 粗判
- 必须已读取 `references/genre-taxonomy.md`

## 执行步骤

### Step 1: 读取输入

- 从 `analysis/analysis.json` 获取 novel-analyzer 的 `summary.genre` 粗判结果
- 读取小说原文（`analysis/cleaned_text.txt`）

### Step 2: 特征提取

从原文中提取以下分类特征：

| 特征维度 | 提取内容 |
|----------|----------|
| 世界观设定 | 古代/现代/未来/异世/架空？有无修炼体系？ |
| 核心金手指 | 系统/重生/穿越/空间/异能/医术/武功？ |
| 冲突类型 | 商战/权谋/修炼/宅斗/刑侦/竞技/生存？ |
| 情感线占比 | 粗略估算：感情线 <30% 还是 ≥30%？ |
| 元素标记词 | 如"斗气""金丹""总裁""王爷""系统面板""丧尸"等 |

### Step 3: 匹配 Taxonomy

- 将提取的特征与 `references/genre-taxonomy.md` 中的每个子类逐项对比
- 每个子类生成匹配得分（特征命中数 / 特征总数）
- 取最高分作为 primary，次高分作为 alternatives

### Step 4: 置信度判定

```
置信度 = 最高分命中率 × 100%
```

- ≥90%：直接确认，无需询问
- 70%-89%：输出分类但标注"建议确认"
- <70%：**必须询问用户**，输出前 3 个候选

### Step 5: 不确定时询问

触发以下任一条件，输出候选列表并请求用户选择：

- 置信度 < 70%
- 最高分与次高分差距 < 15%（两个分类难分高下）
- 命中 taxonomy 交叉/模糊情况表
- 原文信息不足以判定（如仅 3 章刚开头）

询问时展示：
```
检测到文本类型不确定：
- 可能类型1 (置信度: XX%)：因为...
- 可能类型2 (置信度: XX%)：因为...
建议：...
请确认最终分类。
```

### Step 6: 匹配改编注意事项

确认分类后，从 taxonomy 中提取对应子类的"改编注意事项"列表。

### Step 7: 写入输出

写入 `analysis/genre-classification.json`（格式见 Agent 定义）。

## 成功标准

- [ ] 细分到至少二级子类（如"都市-神豪流"而非仅"都市"）
- [ ] 置信度明确标注
- [ ] 不确定情况已询问用户（而非自行猜测）
- [ ] 改编注意事项与分类匹配（非自编）
- [ ] 输出文件 schema 完整
