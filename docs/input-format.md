# 小说输入格式

N2S 当前支持两种输入方式：

- 在网页中直接粘贴小说文本。
- 导入 `.txt`、`.md` 或 `.markdown` 文本文件。

## 推荐格式

使用纯文本，按章节标题分隔，至少 3 章：

```text
第一章 雨夜

正文段落……

第二章 合同

正文段落……

第三章 录音

正文段落……
```

也支持：

```text
第1章 雨夜
Chapter 1
1. 雨夜
```

## 写作建议

- 保留章节标题和正文段落。
- 不需要提前改成剧本格式。
- 可以包含人物对白、旁白、环境描写、心理描写。
- 系统会尝试把心理描写转成动作、对白、独白和可编辑 YAML。

## 模式说明

- 演示：不调用模型，使用内置示例流程，适合检查页面和输出结构。
- 真实模型：调用 `.env` 中配置的模型接口，当前可使用 DeepSeek 配置。
