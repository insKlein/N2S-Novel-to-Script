# 起点中文网题材分类体系 + 改编注意事项

> 基于起点中文网完整分类树，覆盖男频/女频全部一级和二级分类。
> 每个分类附带短剧改编核心注意事项，供 Agent 在做细分判定时自动匹配。

---

## 一、男频（男生频道）

### 1. 玄幻

| 属性 | 内容 |
|------|------|
| **典型子类** | 东方玄幻、异世大陆、王朝争霸、高武世界 |
| **核心爽点** | 修炼升级、越级打脸、功法奇遇、势力碾压 |
| **代表元素** | 斗气/武魂/灵脉/宗门/秘境/丹道 |

**改编注意事项：**
- ✅ 升级流天然适合单元式/关卡式改编，每集=一次突破
- ✅ 大场面可以用 sound_effect + dialogue 暗示，不必实拍
- ⚠️ 跨星系/位面大战需降维处理——改成门内比试或密室对决
- ⚠️ 修炼体系需在前 3 集内讲清，否则观众混乱
- ❌ 禁止长段旁白解释世界观 → 转为角色间问答
- 🔑 金句密度要高："三十年河东三十年河西"级别

### 2. 仙侠

| 属性 | 内容 |
|------|------|
| **典型子类** | 幻想修仙、问道长生、金丹元婴、渡劫飞升 |
| **核心爽点** | 境界突破、法宝对决、天道感悟、因果轮回 |
| **代表元素** | 飞剑/符箓/阵法/灵根/天劫/道心 |

**改编注意事项：**
- ✅ "修仙逆天"天然适合短剧"被打压→反抗"弧线
- ✅ 师徒/道侣关系可强化情感线
- ⚠️ 渡劫场面用音效+特效字幕替代实拍，成本友好
- ⚠️ 道家术语需做口语化翻译 —— "筑基"=打基础，"金丹"=实力质变
- ❌ 禁止宣传封建迷信（审查红线！）→ 强调"个人奋斗"而非"命数"
- 🔑 视觉核心：飞剑(道具) + 灵气光效(lighting 描述)

### 3. 都市

| 属性 | 内容 |
|------|------|
| **典型子类** | 都市生活、系统流、重生逆袭、都市异能、神豪流、高手下山 |
| **核心爽点** | 身份反转、财富碾压、美人倾心、打脸装逼 |
| **代表元素** | 总裁/神医/战神/鉴宝/系统面板 |

**改编注意事项：**
- ✅ **改编最容易**的类别——场景现代、道具现成、受众最广
- ✅ 战神归来/高手下山是短剧爆款模板（身份反转+打脸）
- ✅ 场景控制：办公室/宴会厅/别墅/车内 = 低成本高产出
- ⚠️ 职业细节必须严谨（医生不能开错药、律师不能乱用法条）
- ⚠️ 神豪流需克制炫富描写（审查敏感）
- ❌ 禁止涉黑涉政内容——反派不能是"政府官员"
- 🔑 3 秒开场公式：羞辱→反转（如"这是你的辞职信""不，是你的"）

### 4. 历史

| 属性 | 内容 |
|------|------|
| **典型子类** | 两宋元明、争霸天下、朝堂权谋、架空穿越、种田经商 |
| **核心爽点** | 智谋碾压、科举逆袭、开疆拓土、商战致富 |
| **代表元素** | 科举/战场/朝堂/商路/工匠技艺 |

**改编注意事项：**
- ✅ 种田经商类适合慢节奏叙事——每集一个小成果（开铺/丰收/谈判）
- ⚠️ **必须架空！禁止用真实朝代名**（审查硬性要求）
- ⚠️ 朝堂权谋需简化官僚体系——最多 3 个势力，否则观众混乱
- ⚠️ 战争场面→转为帐中决策/斥候回报/战后清点，不拍千军万马
- ❌ 禁止美化侵略战争或历史反面人物
- 🔑 递进叙事式改编最佳：铺垫→发展→冲突→翻盘

| **代表元素** | 机甲/星舰/基因/虚拟现实/末世基地 |

**改编注意事项：**
- ✅ 末日求生类（丧尸/废土）是短剧热门——场景荒凉成本低
- ✅ 赛博朋克用灯光(lighting 描述) + 屏幕文字(screen_text) 暗示科技感

- ❌ 避免硬科幻术语堆砌（熵增/量子纠缠→观众秒关）
- 🔑 核心冲突仍然是"人"——科幻只是背景，不是主角

- ❌ 不能美化犯罪分子

## 三、频别判定规则

### 判定顺序（按优先级）

1. **主角性别** → 男主大概率男频，女主大概率女频（交叉情况见下）
2. **核心爽点类型** → 能力兑现/地位翻盘=男频；关系拉扯/偏爱背叛=女频
3. **解决冲突方式** → 主角自己动手=男频；借势他人/外部力量=女频
4. **感情线权重** → 感情线 < 事业线=男频；感情线 ≥ 事业线=女频
5. **篇幅节奏** → 战斗/对抗密集=男频；情感拉扯/关系变化密集=女频

### 交叉/模糊情况

| 情况 | 判定建议 | 处理方式 |
|------|---------|---------|
| 女主但核心是能力兑现/地位翻盘 | 女频(大女主) | 按女频+事业线处理 |
| 男主但核心是情感拉扯/关系变化 | 混合 | **需询问用户** |
| 双主角(男女均衡) | 混合 | **需询问用户** |
| 无CP、纯事业、分不出 | 待定 | **需询问用户** |
| 轻小说/同人无法直接判定 | 按原作风 | **需询问用户** |

## 四、不确定情况处理流程

当 genre-classifier Agent 遇到以下情况时，必须暂停并询问用户：

1. **置信度 < 70%** — 单一分类概率不够高
2. **交叉/模糊情况** — 命中上表"需询问用户"行
3. **文本信息不足** — 3 章内看不出明确类型特征
4. **属于多个子类** — 如同时有"玄幻"和"仙侠"特征，无法区分
5. **遇到了不在 taxonomy 中的新类型**

**询问格式**：
```
检测到文本类型不确定：
- 可能类型1 (置信度: XX%)：因为...
- 可能类型2 (置信度: XX%)：因为...
- 建议：...
请确认最终分类，或提供更多信息。
```
